# Этап 0.7: переезд — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Вывести в прод правила, индексы, функции и веб формата данных v2 за одно короткое окно, перенести данные владельца, проверить напоминания и сохранить путь отката. До окна — две мелкие правки веба и список файлов функций, после — снять страж деплоя и перевести документацию на «прод работает на v2».

**Architecture:** Кода мало. До окна три маленькие задачи: экспорт держит ссылку на файл минуту, украинский текст окна переноса, `ignore` функций в `firebase.json`. После переезда одна: удаление `scripts/stage0-deploy-guard.js` и документация. Остальное — инструкция переезда по спецификации 9.3:
- проверка ветки и прогон CI на временной ветке;
- подготовка прода заранее: проверка старых массивов, checkout'ы для выкатки v2 и отката на v1, пробный деплой функций, индексы;
- в день окна — свежий экспорт и репетиция на нём, затем окно: правила → функции v2 (v1 удаляются) → `main` и Deploy Prod → вход владельца, предпросмотр, «Перенести»;
- проверки, откат, позже — удаление старых коллекций.

Шаги на проде выполняет владелец по точным командам плана. Сессия Claude пишет код, проводит репетицию и делает локальные шаги.

**Tech Stack:** Firebase CLI 15 (под Node 22), GitHub Actions (`Deploy Prod` и переиспользуемый `Test & Lint`), gh CLI, эмуляторы Firestore и Auth (репетиция), Vitest 4 + happy-dom, React 19 + Vite 8.

- **Окно:**
  - задачи не править; напоминания могут не прийти;

- В свежем worktree — `npm ci --legacy-peer-deps` и `npm --prefix functions ci`. План зависимостей не меняет; `npm install` не запускать: он переписывает `react`/`react-dom` на `>=16.8.0`.

````js
// @vitest-environment happy-dom
import { afterEach, beforeEach, describe, expect, it, vi } from 'vitest';
import { saveJsonFile } from './saveJsonFile';

describe('saveJsonFile: the browser saves the data as a JSON file', () => {
    let clicks;

    beforeEach(() => {
        vi.useFakeTimers();
        clicks = [];
        vi.spyOn(URL, 'createObjectURL').mockReturnValue('blob:backup');
        vi.spyOn(URL, 'revokeObjectURL').mockImplementation(() => {});
        vi.spyOn(window.HTMLAnchorElement.prototype, 'click').mockImplementation(function click() {
            clicks.push({ href: this.href, download: this.download, inPage: document.body.contains(this) });
        });
    });

    afterEach(() => {
        vi.useRealTimers();
        vi.restoreAllMocks();
    });

    it('offers the data under the file name and leaves no link in the page', async () => {
        saveJsonFile('to-round-backup.json', { tasks: [1] });
        expect(clicks).toEqual([{ href: 'blob:backup', download: 'to-round-backup.json', inPage: true }]);
        const file = URL.createObjectURL.mock.calls[0][0];
        expect(file.type).toBe('application/json');
        expect(await file.text()).toBe('{\n  "tasks": [\n    1\n  ]\n}');
        expect(document.querySelector('a')).toBeNull();
    });

    it('keeps the file for a minute: a browser may read it after the click (Safari asks first)', () => {
        saveJsonFile('to-round-backup.json', { tasks: [] });
        vi.advanceTimersByTime(59999);
        expect(URL.revokeObjectURL).not.toHaveBeenCalled();
        vi.advanceTimersByTime(1);
        expect(URL.revokeObjectURL).toHaveBeenCalledWith('blob:backup');
    });
});
````
