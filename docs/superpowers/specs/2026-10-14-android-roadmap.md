# Нативное Android-приложение To-Round — дорожная карта

Дата: 2026-10-14. Статус: на согласовании.

## Цель

- **А (сейчас):** нативное Android-приложение для себя — удобнее и плавнее веба на телефоне; работает с теми же данными, что и веб.
- **Б (потом):** публикация в Google Play.

Каждый этап ниже — отдельный цикл «спецификация → план → реализация».

## Принятые решения

| Тема | Решение |
|---|---|
| Подход | Приложение пишется с нуля как нативное, а не обёртка над сайтом (TWA, Capacitor) |
| Стек | Kotlin + Jetpack Compose; Firebase Android SDK (Auth, Firestore, Messaging, Installations) |
| Данные | Общий Firebase-проект `todo-flutter-fb8bf` и общий формат данных v2 (этап 0). Веб продолжает работать |
| Хранение | Все данные и настройки — только в Firestore. На устройстве: позиция кнопки «+», кэш Firestore, id установки Firebase |
| Репозиторий | Монорепо: Android-код в `android/` этого репозитория, общий контракт данных — в `contract/` |
| Идентификатор и название | `com.pmobile78.toround`, «ToDo-Round» |
| Версии Android | minSdk 26 (Android 8.0); targetSdk и compileSdk — актуальный API |
| Внешний вид | Material 3 в цветах To-Round; 5 дизайнов веба появляются вместе с экраном пузырей (этап 4) |
| Порядок | Сначала список и редактор задач, экран пузырей — позже |
| Описания задач | Markdown |
| Повтор и напоминания | Без минут: повтор — часы и больше, напоминания — целые часы и больше |
| «Готово» у повторяющейся | Переносит срок на ближайший будущий раз; «Завершить серию» — отдельное действие |
| Уведомления | Сервер, планировщик каждую минуту; переключатель «получать напоминания здесь» на каждом устройстве |
| Mindmap | Вне рамок: карты остаются в вебе |
| Вход | Email и пароль; вход через Google — возможно, на этапе 6 |
| Проверка | Телефон Redmi 9 (Android 12, слабый) и эмулятор `ToRound_API37` (Android 17) |

## Этапы

### Этап 0 — общий формат данных v2 и перевод веба

Спецификация: [2026-10-14-stage-0-data-contract-v2-design.md](2026-10-14-stage-0-data-contract-v2-design.md).

Готово, когда веб, функции и правила работают только с форматом v2, данные перенесены и проверены, напоминания приходят.

### Этап 1 — основа Android-приложения

Спецификация: [2026-10-22-stage-1-android-foundation-design.md](2026-10-22-stage-1-android-foundation-design.md).

- Проект `android/`: Gradle, Kotlin, Compose, Material 3, тема в цветах To-Round, ресурсы en/uk.
- Подпись: debug-ключ для разработки, ключ release хранится вне git.
- Firebase: вход, регистрация, сброс пароля, выход; Firestore с офлайн-кэшем.
- Слой данных по контракту v2: модели, преобразование документов, репозитории задач, категорий и настроек; тесты на фикстурах из `contract/`.
- Простой экран — список активных задач (только просмотр) как доказательство совместимости.

Готово, когда на Redmi 9 можно войти в свой аккаунт и увидеть те же задачи, что в вебе, а тесты контракта проходят.

### Этап 2 — задачи

- Список: вкладки (активные, запланированные, выполненные, корзина), сортировка, поиск, фильтр по категориям.
- Редактор: название, описание (просмотр Markdown с форматированием и правка текста Markdown), категория, срок, напоминания, повтор, размер пузыря; «Готово», «Завершить серию», удаление и восстановление.
- Категории: создание, правка, удаление с отменой, перестановка.
- Расчёт следующего повтора по общим примерам `contract/fixtures/recurrence.json`.

Готово, когда всё, что делается со списком задач в вебе, можно сделать на телефоне, а изменения видны в обе стороны без перезагрузки.

### Этап 3 — уведомления

- Регистрация устройства (id установки Firebase), переключатель «получать напоминания здесь», разрешение на уведомления (Android 13+), канал уведомлений.
- Показ уведомлений из data-сообщений FCM; тап открывает задачу.
- Инструкция для MIUI: разрешить автозапуск и снять ограничения батареи, иначе оболочка Xiaomi выгружает приложение и уведомления не доходят.

Готово, когда на Redmi 9 приходят напоминания и «просрочено», тап открывает нужную задачу, а при выключенном переключателе уведомлений нет.

### Этап 4 — экран пузырей

- Физика (JBox2D или свой движок для кругов), бросок и тап, подписи, пульсация просроченных, «лопание» со звуком и частицами.
- 5 дизайнов в светлом и тёмном вариантах; на Android ниже 12/13 эффекты размытия и шейдеры заменяются упрощёнными.
- Плавная работа на Redmi 9 при типичном числе задач.

### Этап 5 — настройки и прочее

- Настройки, общие с вебом (`settings`): тема, дизайн, шрифт подписей, язык, главный экран, фон пузырей, панель категорий.
- Экспорт и импорт бэкапа v2 через системный выбор файла, смена пароля, «О приложении».

### Этап 6 — Google Play (цель Б)

- Подпись релиза (Play App Signing), политика конфиденциальности, раздел «Безопасность данных».
- Прогон на эмуляторе с Android 8.
- Закрытое тестирование и верификация разработчика — по правилам Google, актуальным на момент публикации (для новых личных аккаунтов ранее требовалось 12 тестеров на 14 дней).
- Страница в магазине: описание, скриншоты, иконка.
- Вход через Google — по желанию.

## Отложено

- **Удобное редактирование чек-листов на телефоне.** После этапа 2. До этого Android-приложение показывает чек-листы и не портит их синтаксис при правке текста.
- **Mindmap на Android.**
- **Удаление старых коллекций Firestore** (`user-bubbles`, `user-tags`, `user-fcm-tokens`). Владелец делает это вручную, когда Android-приложение уже в работе.

## Окружение разработки

- Android Studio Rabbit 1 (2026.2.1) — `/media/big_disk/android/android-studio`, запуск командой `studio`.
- SDK — `/media/big_disk/android/sdk` (`ANDROID_HOME`). `sdkmanager` объявлен устаревшим, замена — `android sdk …` из `cmdline-tools/latest/bin`.
- Эмулятор `ToRound_API37`: Android 17, образ с Google Play, 2 ГБ памяти.
- `~/.android`, `~/.gradle`, `~/.cache/Google`, `~/.config/Google`, `~/.local/share/Google` — ссылки на `/media/big_disk/android/home/…`: системный диск почти заполнен.
- Переменные окружения — `/media/big_disk/android/android-env.sh`, подключён из `~/.bashrc` и `~/.profile`.
- JDK для Gradle — JBR из Android Studio (`/media/big_disk/android/android-studio/jbr`), а не системный JDK 25.
- Памяти 14 ГБ: эмулятор вместе с Android Studio работает впритык, поэтому основная проверка — на телефоне через adb (USB или Wi-Fi).
