# Документация ToDo-Round

Индекс документации проекта. Обзор приложения и быстрый старт — в [корневом README](../README.md).

## Настройка и эксплуатация

| Документ | О чём |
|---|---|
| [environment.md](environment.md) | Переменные окружения, файлы `.env`, конфигурация и её валидация |
| [firebase.md](firebase.md) | Firebase: аутентификация, модель данных Firestore, правила доступа |
| [deployment.md](deployment.md) | Ручной деплой на GitHub Pages через GitHub Actions и управление версиями |
| [favicon.md](favicon.md) | Набор иконок и web-манифест |
| [android.md](android.md) | Android-приложение: сборка, телефон и эмулятор, релизный ключ |

## Как устроены фичи

| Документ | О чём |
|---|---|
| [notifications.md](notifications.md) | Дедлайны, напоминания, повторы; пульсация на клиенте и серверный планировщик FCM |
| [i18n.md](i18n.md) | Интернационализация: namespaces, добавление языка |
| [migration.md](migration.md) | Перенос данных v1 → v2 при первом входе, резервная копия (экспорт и импорт), репетиция переноса на эмуляторе, удаление старых коллекций |
